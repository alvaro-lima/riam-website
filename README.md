# Grandma Solitaire (Android)

A simple, ad-free Android solitaire app with extra large cards and text for improved readability.

## Goals
- **No ads or tracking SDKs**.
- **Large cards and labels** for low-vision players.
- **Simple tap controls** (draw from deck, tap destination pile).

## Build
1. Open in Android Studio (Jellyfish+ recommended).
2. Let Gradle sync.
3. Run on an emulator or Android device (API 24+).

## Notes
This project intentionally keeps the UI and rules straightforward so it is easy to see and easy to play.
